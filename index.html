SYSTEMS THINKING GAME

The Complexity Game

Build the system. Live with the consequences.

ROUND 1 / 8

Every system starts simple. Then decisions accumulate.

In this game, you will make eight decisions that gradually shape a system, with each decision affecting value, agility, and complexity, while earlier choices can change how later decisions behave.

THE IDEA

A decision that makes sense in isolation can create consequences for the system as a whole.
Value What the system delivers.
Agility How easily the system can respond and adapt.
Complexity How difficult the system is to operate and change.

There is no single correct path. The objective is not to maximize one number, but to see what kind of system your decisions create.
